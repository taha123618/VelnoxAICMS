# Rector Code Refactoring

Rector reconstructs PHP code to automate refactoring, keeping code modern and clean.

## Running Rector

Process dry-run:
```bash
vendor/bin/rector process --dry-run
```
Apply code refactoring directly:
```bash
composer rector
```
Or:
```bash
vendor/bin/rector process
```

## Configuration

Rector is configured in `rector.php` in the project root.
Key features:
- `withPaths()`: Directories to process.
- Dead code removal levels and code quality levels.
- Laravel-specific rules using `driftingly/rector-laravel` rules.

## Best Practices

- Always run tests and commit changes before running `composer rector` as it directly modifies source files.
- Inspect the diff generated by Rector carefully before staging changes.
